Object
Exact fields / example
facilities[]
candidate_id, kind, size, input_t_per_year, output_t_per_year. Example R1, refinery, small, 500, 100.
Coordinates join from candidates; report them in UI/export.
flows[]
from_id, to_id, stage, tonnes_per_year, mode. Example R1, TRK, refinery_airport, 25, barge.
costs
capex_usd; annualised_capex_usd_per_year; fixed_opex_usd_per_year; variable_opex_usd_per_year;

truck_trips[]
from_id, to_id, stage, small_trip_equivalents_per_year, large_trip_equivalents_per_year. Example S1, D1,
source_depot, 166.666667, 55.555556. Truck edges only.
Validation
valid:bool; checks:list[{name:str,passed:bool,detail:str}]; errors:list[str]. No feasible result => valid=false, not
evidence of a solver defect.
Patch
schema_version:str; status:ready|clarify|unsupported;
changes:list[{airport_id:str,new_demand_t_per_year:number}]; question:str|null.
Service response
Exactly scenario, result, validation, explanation, clarification. result and validation may be null while clarification
is pending. explanation:str; clarification:str|null.
Failure: infeasible proves no solution; no_solution means no incumbent found before the solver stopped, not
proven infeasibility. Both use empty facilities/flows/deliveries/costs and null gap. Never show zeros as a cheap
network. API error leaves the scenario unchanged. Hide unvalidated flows.
CapEx is upfront USD, not added directly to annual total. opex = fixed + variable; total = annualised CapEx + opex
+ transport. Do not double-count the fixed/variable breakdown. TRK remains stage refinery_airport; mode is
barge.

Deterministic baseline, now feasible
Open a small depot at each of the 80 sources and a large refinery at each of the eight refinery candidates. Each
source may send only to its co-located depot. All depot-refinery and refinery-airport links remain available.
Optimise continuous flows only, with the same costs, yields and demand as the MILP.
Each source has less than 150 kt/year, so its small depot can accept its entire supply. Eight large refineries
provide 8 x 1,087 = 8,696 kt/year intake. Construct a feasible base by collecting 6,000/6,800 of each source and
distributing intake equally: 750 kt per refinery. For BPN+20%, collect 6,300/6,800 and send 787.5 kt per refinery.
Both are below 1,087. Distribute SAF to each airport in proportion to its demand. All required links exist.
At least ceil(6,000/1,087)=6 large refineries are needed for base, and ceil(6,300/1,087)=6 for BPN+20%. The eight
distinct candidates are sufficient. Finite candidates are our team assumption; do not claim the optimum over all
land in Kalimantan.
Why the comparison is fair
The baseline feasible set is contained in the MILP feasible set. Same scenario, transport factors, objective and
costs. Base vs BPN is a demand-change comparison, not a savings claim. Only compare each MILP result with its
matching baseline.
